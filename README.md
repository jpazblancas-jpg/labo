# Laboratorio de Investigación, Desarrollo e Innovación

Presentación web interactiva de Ciencias de la Creatividad.

## Abrir

Abre `index.html` en un navegador o sirve esta carpeta con `python3 -m http.server 8000`.

Incluye 12 secciones, navegación por teclado e índice, transiciones en profundidad y diagramas vectoriales.

Los cuerpos usan Aktiv Grotesk cuando está instalada en el dispositivo, con Arial como respaldo.

Sitio: https://laboratorio-creatividad-lidi.estudiodose12.chatgpt.site
